# LED光通信レシーバー

FPGA(Cyclone V E 開発キット)の拡張ボードのLEDが送る光の点滅を、スマホのカメラや動画から読み取り、文字に戻すWebページです。

- 直列方式(`optical_tx`):D1=クロック、D3=データ1ビット
- 並列方式(`optical_par`):D1=クロック、D2〜D9=1バイト、D10=パリティ
- カラーモード(`optical_par2` のPB3):D2〜D9の赤=1バイト目、緑=2バイト目、D10=それぞれのパリティ

## 使い方

- PCで使う:このフォルダごと保存し、`index.html` をChromeで開く(動画の読み込みとデモ信号が使える)
- スマホのカメラで使う:GitHub Pagesなど `https://` のページに置いて開く(カメラは https でしか使えない)

## ファイルの構成

読み込む順番に並べています。`app.js` が最後に読み込まれ、そこで動き始めます。

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の部品(ボタン・表示欄) |
| `style.css` | 見た目 |
| `js/tx-model.js` | 送信側のモデル(VHDLと同じ動き)。デモ信号とテストで使う |
| `js/channel.js` | 明るさ → 0/1 の判定 |
| `js/decode-serial.js` | 直列方式の復号 |
| `js/decode-parallel.js` | 並列方式の復号(旧方式と高精度受信) |
| `js/decode-color.js` | カラーモードの復号(赤と緑を別々に読み、2バイトずつ組み立てる) |
| `js/tracking.js` | 手ブレ補正 |
| `js/detect.js` | LEDの場所の自動検出 |
| `js/demux.js` | MP4 / MOV の読み取り |
| `js/view.js` | 映像の取り込み・描画・デモ信号 |
| `js/sources.js` | 動画ファイルとカメラ |
| `js/exposure.js` | カメラの露出の調整と、白飛びの割合の表示 |
| `js/diag.js` | 診断表示(LEDごとの判定・明暗の差・訂正回数)とログのCSV保存 |
| `js/app.js` | 操作と表示の更新 |

## 高精度受信のしくみ(decode-parallel.js)

1. クロック再生:クロックLEDの切り替わり時刻から周期と位相を推定し、見逃したシンボルも補う
2. 複数コマの平均:シンボルの中心付近のコマを、中心に近いほど重く平均して判定する
3. パリティ訂正:パリティが合わなければ、一番自信のない(境目に近い)ビットを反転する
4. 多数決:繰り返し届くフレームを、文字の位置ごとに多数決する
